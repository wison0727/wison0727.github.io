## 1. 概述

FRNC-5PC（**F**urnace **R**eaction and **N**etwork **C**alculation, 5th Revision, **P**ersonal **C**omputer）是一款专门用于乙烯裂解炉管内反应与结焦过程模拟的专业工程软件。该软件由比利时布鲁塞尔自由大学（ULB）Gabriel Froment 教授与 Klaus Bischoff 教授团队开发，后经 KBR（Kellogg Brown & Root）公司持续维护和商业化推广，至今已有 40 余年工业应用历史。

FRNC-5PC 基于自由基反应动力学机理，能够精确模拟烃类原料在裂解炉管内的热裂解反应、温度分布、压力分布以及焦炭沉积过程，是全球乙烯行业裂解炉设计、优化和运行管理的核心工具之一。

## 2. 软件核心功能

### 2.1 自由基反应动力学模型

FRNC-5PC 采用基于详细自由基机理的动力学模型，而非简化的经验关联式：

- **反应网络规模**：包含数千个基元反应，覆盖 C1~C20+ 烃类的热裂解路径
- **自由基类型**：完整追踪 H·、CH₃·、C₂H₅· 等关键自由基的生成、传递与终止过程
- **裂解产物**：可预测乙烯、丙烯、丁二烯、BTX 芳烃等全谱产物分布
- **反应器模型**：一维拟均相管式反应器模型，沿管长方向逐段积分求解

> FRNC-5PC 的动力学模型经过数十年工业数据验证，对不同原料和工况的预测精度远优于经验模型。

### 2.2 结焦动力学模拟

结焦模拟是 FRNC-5PC 最核心的差异化功能：

- **结焦机理**：模拟管壁表面催化结焦和气相均相结焦两种机制
- **焦炭生长**：预测焦层厚度沿管长方向的分布
- **运行周期**：计算从清焦到下次清焦的允许运行天数
- **管壁温升**：考虑焦层热阻导致的管壁温度升高
- **清焦策略**：评估不同操作条件对清焦周期的影响

### 2.3 辐射段传热模拟

- **炉膛热强度分布**：支持自定义沿管长方向的热通量分布曲线
- **管外传热**：模拟炉膛烟气对管壁的辐射与对流传热
- **管内传热**：考虑管内膜传热系数随流体物性的变化
- **管壁温度计算**：结合焦层热阻精确计算金属管壁温度

### 2.4 对流段模拟

- **原料预热段**：模拟原料在对流段的预热和部分汽化过程
- **稀释蒸汽过热**：计算稀释蒸汽的过热度
- **排烟温度**：预测烟气排放温度，评估余热回收效率

### 2.5 产品收率预测

FRNC-5PC 可输出完整的裂解产物分布：

| 产物类别 | 具体组分 |
|---------|---------|
| 烯烃 | 乙烯、丙烯、丁二烯、异戊二烯 |
| 炔烃 | 乙炔、甲基乙炔、丙二烯 |
| 芳烃 | 苯、甲苯、二甲苯、苯乙烯 |
| 烷烃 | 甲烷、乙烷、丙烷、丁烷 |
| 其他 | 氢气、C5+ 液体、裂解汽油 |

## 3. 输入参数与数据要求

### 3.1 原料参数

| 参数项 | 说明 | 示例 |
|-------|------|------|
| 原料组成 | 各组分摩尔分数或质量分数 | 正构烷烃、异构烷烃、环烷烃、芳烃 |
| 原料流量 | 质量流量或摩尔流量 | 50 t/h |
| 稀释蒸汽比 | 蒸汽与原料的质量比 | 0.3~0.6 |
| 原料预热温度 | 进入辐射段前的温度 | 550~620 °C |

### 3.2 炉管几何参数

- 管外径与壁厚
- 管总长度（展开长度）
- 盘管构型（直管、U 型管、螺旋管）
- 管排数与管间距
- 弯头数量与类型

### 3.3 操作条件

| 参数 | 典型范围 |
|-----|---------|
| 出口温度 COT | 780~850 °C |
| 出口压力 | 0.1~0.25 MPa (G) |
| 热通量峰值 | 80~120 kW/m² |
| 运行周期 | 30~90 天 |

### 3.4 炉膛热强度分布

软件允许用户输入沿管长方向的热通量分布曲线，通常分为三种典型模式：

```
模式 A：前高后低型（适用于轻质原料）
模式 B：均匀分布型（适用于重质原料）
模式 C：中间峰值型（适用于石脑油）
```

## 4. 输出结果解读

FRNC-5PC 的计算结果主要包括以下几个部分：

### 4.1 沿管长温度/压力分布

输出沿炉管展开长度方向的流体温度、管壁温度和压力变化曲线，是评估裂解深度和管壁安全的关键依据。

### 4.2 产品收率表

列出各产物的摩尔收率、质量收率和选择性，以表格和图表形式展示。

### 4.3 结焦预测

- 沿管长方向的焦层厚度分布
- 管壁最高温度及其位置
- 清焦周期预测
- 不同运行天数下的管壁温升趋势

### 4.4 热负荷平衡

- 辐射段总热负荷
- 对流段热回收量
- 排烟热损失
- 整炉热效率

```

│     └─ 管径、长度、构型、弯头            │

```

## 6. 工业应用场景

### 6.1 新炉设计

在裂解炉新建项目中，FRNC-5PC 用于：

- 确定最优盘管构型和管径
- 计算所需传热面积和管排数
- 确定辐射段热负荷和烧嘴布置
- 评估不同原料的裂解性能

### 6.2 装置扩能改造

- 评估现有炉管在提量工况下的安全性
- 分析增产乙烯的可行操作窗口
- 预测改造后的清焦周期变化

### 6.3 原料优化

- 对比不同石脑油、加氢尾油等原料的裂解性能
- 优化原料配比以最大化目标产物收率
- 评估重质原料对结焦和运行周期的影响

### 6.4 运行优化

- 在线调整 COT 以平衡收率与结焦速率
- 优化蒸汽比以降低能耗并抑制结焦
- 制定合理的清焦周期计划

## 7. 与 SPYRO 的对比

FRNC-5PC 与 SPYRO（Technip Energies 开发）是乙烯行业两大主流裂解模拟软件：

| 对比项 | FRNC-5PC | SPYRO |
|-------|---------|-------|
| 开发机构 | KBR (原 S&W) | Technip Energies |
| 动力学校 | 自由基详细机理 | 自由基详细机理 |
| 结焦模型 | 内置详细结焦动力学 | 内置结焦模块 |
| 市场定位 | KBR 工艺包配套 | 独立商业授权 |
| 用户群体 | KBR 技术许可装置 | 更广泛的独立用户 |
| 界面风格 | 经典工程软件风格 | 较新的图形界面 |

> 两者在计算精度上相当，选择通常取决于工艺包来源和企业授权关系。

## 8. 软件版本与获取方式

- **当前版本**：FRNC-5PC（PC 平台版本）
- **授权方式**：商业授权，按站点或按席位授权
- **获取途径**：通过 KBR 公司或其授权代理获取
- **技术支持**：KBR 提供培训、技术咨询和版本更新服务
- **运行环境**：Windows 操作系统

## 9. 小结

FRNC-5PC 作为裂解炉模拟领域的经典软件，凭借其严谨的自由基动力学模型和成熟的结焦预测能力，在全球乙烯行业享有极高的认可度。对于裂解炉设计工程师而言，熟练掌握 FRNC-5PC 的使用，是进行炉管优化设计和运行管理的重要技能。
